GIGANG 3.6.0 — 복사/붙여넣기 · 다운로드/업로드 내용 일치 연결

설치 및 실행
상위 폴더의 실행방법.txt를 읽어주세요.
전체: start-all.bat / 관리자 대시보드만: ADMIN_START.bat / 이용자 Agent만: USER_START.bat
확장 폴더: app_files/browser_extension

복사 -> 붙여넣기
- https://desktop-oli.tail2bbbea.ts.net/db 의 customerTable 데이터 행을 선택해서 복사합니다.
- 같은 Chrome 프로필의 다른 사이트에 동일 텍스트를 붙여넣으면 내용 일치를 기록합니다.
- 선택된 원문은 확장에서 잠깐 읽어 SHA-256 비교값을 계산합니다. 서버로 보내지 않습니다.
- 줄바꿈 CRLF/CR은 LF로 통일합니다. 나머지 공백/탭/문자가 바뀌면 일치하지 않습니다.
- 검색창 복사, 일부만 붙여넣기, 100만 자 초과 텍스트, 비보안 페이지 등은 비교 대상에서 제외됩니다.
- 사이트가 자체 복사 버튼으로 Clipboard API를 호출하거나 복사 이벤트를 바꾸는 경우 별도 연동이 필요합니다.

다운로드 -> 업로드
- 사내 DB의 엑셀 다운로드 링크를 일반 왼쪽 클릭합니다.
- 확장이 로그인된 상태로 파일 응답을 한 번 받아 해시를 계산하고 그 동일한 바이트를 저장합니다.
- 페이지 오른쪽 아래에 다운로드 준비 상태가 표시됩니다.
- Chrome에서 다운로드 완료가 확인되고 원본 기록이 서버에 저장된 후 비교 대상으로 등록됩니다.
- 다른 사이트의 파일 선택창에서 같은 파일을 선택하면 내용 일치를 기록합니다.
- 파일 이름만 바꾸어도 일치합니다. 파일을 편집하거나 다시 저장/압축하면 바이트가 달라져 일치하지 않을 수 있습니다.
- 최대 50 MiB입니다. 완료되지 않거나 취소된 다운로드는 출처로 등록하지 않습니다.
- Ctrl+클릭/새 탭/주소 직접 접근/기존 파일/확장 설치 전 다운로드는 일반 감지는 가능하나 파일 내용 연결 대상이 아닙니다.
- 다운로드 준비 실패 시 화면에 이유가 표시됩니다. Ctrl+클릭으로 원래 다운로드를 사용할 수 있으나 내용 일치 비교는 제외됩니다.
- 사내 DB 서버 코드를 수정할 필요는 없습니다. 현재 /db/download 링크 구조에 맞춰 구현했습니다.

연결 범위
- 같은 Chrome 프로필에서 최근 30분, 텍스트/파일 출처 합계 최신 100건.
- 비교값은 확장 프로그램의 session 저장소에만 둡니다. 브라우저 종료/확장 재등록 시 초기화됩니다.
- 원문과 해시값은 중앙 서버에 보내지 않습니다. 사이트·시각·파일명 같은 기존 메타데이터와
  기록 ID, 일치 여부, 연결된 원본 기록 ID, 비교 방법, 경과 시간만 전송합니다.
- 같은 내용의 출처가 여러 개면 가장 최근 것을 표시하고 후보 개수도 남깁니다.
  동일 내용이라는 증거이며, 복제본 중 유일한 원본을 증명하는 기능은 아닙니다.
- 복사 실패/앱의 자체 클립보드 변환/파일 수정/사진 촬영/OCR/드래그앤드롭 우회까지 감지하는 기능은 아닙니다.
- 원본 이벤트를 서버에 저장하지 못했으면 출처로 등록하지 않습니다. Agent와 서버 연결을 유지하세요.

위험도와 화면
- 사내 DB 복사/다운로드 시작 -> 기존 WATCH.
- 동일 내용의 외부 붙여넣기/파일 선택 -> HIGH 및 '사내 자료 내용 일치 · 외부 입력 시도' 사건.
- 기존 HIGH/CRITICAL 상태는 낮추지 않습니다.
- 사이트 승인 여부와 무관하게 사내 자료의 외부 입력 일치에 HIGH를 적용하는 현재 데모 정책입니다.
- 확장 팝업에서 '사내 자료와 내용 일치' / '일치 기록 없음' / '내용 비교 안 됨'을 구분합니다.
- 중앙 서버 파이프라인 표에 내용 비교, 일치한 출처, 원본 기록 ID, 기록 ID가 추가됩니다.
- 종합 관제 사건에 출처 -> 목적지와 원본 기록 ID가 표시됩니다.
- 이는 붙여넣기/파일 선택 시도입니다. 실제 외부 전송 완료나 유출 확정이라고 표시하지 않습니다.

검증 결과
- 확장 코드 테스트: 실제 SHA-256 계산, 줄바꿈 정규화, 일치/수정/파일명 변경,
  다운로드 완료 전 제외, 비교 기간 만료, 세션 초기화, 원문/해시값 전송 제외.
- 다운로드 코드 테스트: 파일 응답 한 번만 받아 해시한 바이트와 저장 Blob 바이트가 같은지 확인.
- 연결 테스트: 확장 결과 -> Agent 허용 필드 검사 -> 서버 raw_data 형식 -> 수집기 ->
  임시 SQLite HIGH 저장 -> 출처 연결 사건 생성 -> 재수집 중복 제외 통과.
- 실제 Chrome에 설치해서 운영 DB 사이트부터 외부 사이트까지 실행하는 시연은 아직 하지 않았습니다.
- 운영 서버를 배포하거나 현재 실행 중인 프로그램을 교체하지 않았습니다.

기존 설정이 포함된 전체 패키지입니다. ZIP 전체를 공개 저장소에 올리지 마세요.
