GIGANG 사용자 설치/실행

1) USER_START.bat 실행
   - 중앙 차단 정책을 받아 Windows에서 실제 사이트를 차단합니다.
   - 관리자 대시보드는 열리지 않습니다.

2) 파일 업로드/붙여넣기 감지가 필요하면 Chrome 확장을 1회 설치
   - chrome://extensions
   - 개발자 모드 ON
   - 압축해제된 확장 프로그램 로드 -> GIGANG_User_Client\browser_extension 선택

3) 역할
   - 사이트 차단: Windows Agent
   - 파일 선택/붙여넣기 감지: Chrome 확장
   - 확장자가 없어도 사이트 차단은 유지됩니다.

4) USER_STOP.bat
   - 사용자 Agent를 중지하고 GIGANG이 hosts에 추가한 차단 블록을 제거합니다.
