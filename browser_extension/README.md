# GIGANG Upload Detector (크롬 확장)

파일 첨부 시도를 감지해 같은 PC의 Agent에게 알려주는 확장 프로그램입니다.

> `manifest.json` 은 JSON 형식이라 주석을 넣을 수 없어(주석을 넣으면 크롬이 확장을 읽지 못합니다)
> 설정 설명을 이 파일로 분리했습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장의 신분증. 크롬에게 "이 확장이 무엇이고 어떻게 동작하는지" 알려주는 설정 파일 |
| `content.js` | 실제 감지 코드. 파일 선택을 감지해 Agent(`127.0.0.1:8765`)로 전달 |

## manifest.json 설정 풀이

```json
{
  "manifest_version": 3,          // 크롬 확장 규격 버전. 현재 크롬은 3만 받습니다
  "name": "GIGANG Upload Detector",
  "version": "1.0",
  "description": "Detects file selection attempts in the browser.",

  "permissions": [],              // ← 요구하는 권한이 하나도 없습니다

  "content_scripts": [
    {
      "matches": ["<all_urls>"],  // 모든 사이트에 content.js 를 삽입
      "js": ["content.js"],
      "run_at": "document_idle"   // 페이지 로딩이 끝난 뒤에 실행
    }
  ]
}
```

### `permissions: []` 가 비어 있는 이유

권한을 하나도 요구하지 않습니다. 설치할 때 크롬이 "이 확장이 무엇을 할 수 있습니다"라는
경고창을 띄우지 않는 이유가 이것입니다.

`content_scripts` 방식은 페이지 안에서 동작하는 것이라 별도 권한이 필요 없습니다.
탭 정보를 읽거나 브라우저 기록에 접근하려면 그때 권한이 필요합니다.
이 확장은 그런 일을 하지 않습니다.

### `matches: ["<all_urls>"]` 의 의미

모든 웹사이트에서 동작합니다. 어느 사이트에 기밀을 올릴지 미리 알 수 없으므로
전체를 대상으로 잡았습니다.

다만 감지 범위를 좁히고 싶다면 여기를 수정하면 됩니다. 예를 들어
생성형 AI 사이트에서만 동작시키려면 이렇게 바꿉니다.

```json
"matches": ["*://*.chatgpt.com/*", "*://*.claude.ai/*"]
```

### `run_at: "document_idle"` 의 의미

페이지 로딩이 끝난 뒤에 스크립트를 실행합니다.
더 일찍 실행하는 `document_start` 도 있지만, 사용자가 파일을 고르는 것은
페이지가 다 뜬 뒤의 일이므로 굳이 서두를 필요가 없습니다.
페이지 로딩 속도에도 영향을 주지 않습니다.

## 설치 방법

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** 클릭
4. 이 `browser_extension` 폴더 선택
5. 테스트할 사이트를 새로고침

## 동작 확인 방법

1. Agent(`start-agent.bat`)를 먼저 실행합니다
2. 아무 사이트에서 파일 첨부 버튼을 눌러 파일을 하나 고릅니다
3. F12 → Console 탭에 `[GIGANG] FILE_UPLOAD_ATTEMPT` 가 찍히는지 확인합니다
4. `Agent 전달 성공` 이 함께 나오면 정상입니다
   - `Agent 연결 실패` 가 나오면 Agent가 꺼져 있는 것입니다

## 감지 한계

시연 전에 알아두어야 할 부분입니다.

- `<input type="file">` 형태의 일반 파일 선택창만 감지합니다
- **드래그앤드롭은 감지하지 못합니다**
- 클립보드 붙여넣기도 감지하지 못합니다
- 여러 파일을 골라도 첫 번째 파일만 전송합니다
- 파일을 **고른 시점**에 기록됩니다. 고르고 나서 취소해도 로그는 남습니다
  (즉 "업로드 완료"가 아니라 "업로드 시도"입니다)

## 개인정보

파일의 **이름과 크기만** 전송합니다. 파일 내용을 읽거나 보내는 코드는 없습니다.
